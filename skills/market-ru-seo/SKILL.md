# SEO-аудит контента (Google + Яндекс)

## Назначение скилла

Проведение комплексного SEO-аудита веб-страницы или сайта для двух поисковых систем: **Google** и **Яндекс**. Скилл сочетает автоматический анализ через `scripts/analyze_page.py` с экспертной ручной проверкой.

**Особенности:**
- Google и Яндекс имеют разные алгоритмы и факторы ранжирования
- Для России рекомендуемый вес: **Яндекс 70%, Google 30%**
- Автоматический скрипт рассчитывает оба Score и комбинированный
- **Шкала оценки: 0-20 для каждой системы** (сумма всех факторов)

## Когда использовать

- Пользователь предоставляет URL и просит SEO-анализ
- Пользователь хочет улучшить позиции в органической выдаче
- Пользователь спрашивает про on-page SEO, meta-теги, технический SEO
- Запускается командой `/market-ru seo <url>`

## Как выполнить

### Шаг 1: Запуск автоматического анализа

```bash
python3 scripts/analyze_page.py <url>
```

Скрипт извлекает данные и рассчитывает:
- **google_seo** — Score для Google (0-20)
- **yandex_seo** — Score для Яндекс (0-20)
- **seo_combined** — Комбинированный Score (Google×0.30 + Яндекс×0.70) → 0-20
- **google_seo_breakdown** — детализация по 8 факторам
- **yandex_seo_breakdown** — детализация по 8 факторам

### Шаг 2: Автоматическая генерация чеклистов и рекомендаций

На основе данных `scores.google_seo_breakdown` и `scores.yandex_seo_breakdown` автоматически генерируются:
- **Section 3: Чеклист On-Page SEO** — статус каждого фактора (✅/⚠️/❌)
- **Section 4: Приоритизированные рекомендации** — на основе оценок факторов

### Шаг 3: Ручная проверка (опционально)

Для углублённого анализа используйте экспертные чеклисты из раздела "Экспертные чеклисты".

## Scoring Methodology (0-20)

### Google SEO Score (сумма = 20)

| Фактор | Макс | Описание | Логика оценки |
|--------|------|----------|---------------|
| **Indexability** | 4 | Первичная проверка индексации. Если страница закрыта от индекса (noindex) или canonical указывает не на себя — остальные факторы не имеют смысла. | 4 = ok, 2 = нет canonical, 1 = указывает не туда, 0 = noindex |
| **Title Tag** | 3 | Проверка: наличие, отсутствие дублей с H1, длина 30-70 символов. | 3 = ok, 2 = только длина, 1 = частично, 0 = отсутствует |
| **H1 Tag** | 3 | Проверка: наличие и строгое правило "только один H1 на страницу". | 3 = 1 H1, 0 = отсутствует/много |
| **Schema.org / JSON-LD** | 3 | Наличие структурированных данных (Organization, Article, Product). | 3 = есть, 0 = нет |
| **Meta Description** | 2 | Проверка наличия и длины (до ~155 символов). | 2 = ok, 1 = длина не оптимальна, 0 = отсутствует |
| **Mobile Viewport** | 2 | Наличие `<meta name="viewport"...>`. | 2 = есть, 0 = нет |
| **Images Alt** | 2 | Отношение количества `<img>` с заполненным alt к общему числу картинок. | 2 = ≥80%, 1 = ≥50%, 0 = <50% |
| **HTTPS** | 1 | Проверка протокола. | 1 = HTTPS, 0 = HTTP |

**Формула Google:** `google_seo = сумма_факторов` (от 0 до 20)

### Яндекс SEO Score (сумма = 20)

| Фактор | Макс | Описание | Логика оценки |
|--------|------|----------|---------------|
| **Коммерческие маркеры** | 4 | Regex: телефоны (8-800), email, ИНН/ОГРН, адреса. | 4 = ≥4 маркера, 2 = ≥2, 1 = ≥1, 0 = нет |
| **Title Tag** | 3 | Аналогично Google: наличие и длина. | 3 = ok, 2 = длина, 1 = частично, 0 = отсутствует |
| **H1 Tag** | 3 | Наличие и единственность на странице. | 3 = 1 H1, 0 = отсутствует/много |
| **Indexability** | 3 | noindex + canonical. | 3 = ok, 1 = проблемы, 0 = noindex |
| **Микроразметка (OG/Schema)** | 3 | og: tags + Schema. | 3 = ≥3 OG + Schema, 2 = есть, 0 = нет |
| **Счётчики (Метрика/Вебмастер)** | 2 | mc.yandex.ru, yandex-verification. | 2 = оба, 1 = один, 0 = нет |
| **Meta Description** | 1 | Яндекс чаще игнорирует, но влияет на CTR. | 1 = есть, 0 = нет |
| **HTTPS** | 1 | Наличие защищённого соединения. | 1 = HTTPS, 0 = HTTP |

**Формула Яндекс:** `yandex_seo = сумма_факторов` (от 0 до 20)

### Комбинированный Score

```
seo_combined = google_seo × 0.30 + yandex_seo × 0.70
```

Округление до 1 знака после запятой.

## Автоматическая генерация Section 3 (Чеклист On-Page SEO)

### Правила определения статуса

| Условие | Статус | Иконка |
|---------|--------|--------|
| score == max | ✅ Пройдено | `status-pass` |
| 0 < score < max | ⚠️ Требует работы | `status-warn` |
| score == 0 | ❌ Не пройдено | `status-fail` |

### Пример автоматического чеклиста (Google)

| Фактор | Баллы | Макс | Статус | Причина |
|--------|-------|------|--------|---------|
| Indexability (Robots/Canonical) | 1 | 4 | ❌ | Canonical указывает не на себя |
| Title Tag | 1 | 3 | ❌ | Длина 7 символов (ожидалось 30-70) |
| H1 Tag | 0 | 3 | ❌ | H1 отсутствует |
| Schema.org / JSON-LD | 0 | 3 | ❌ | Разметка не найдена |
| Meta Description | 0 | 2 | ❌ | Отсутствует |
| Mobile Viewport | 2 | 2 | ✅ | Присутствует |
| Images Alt | 0 | 2 | ❌ | 0/14 с alt |
| HTTPS | 0 | 1 | ❌ | HTTP |

## Автоматическая генерация Section 4 (Приоритизированные рекомендации)

### Правила приоритизации

| Условие | Приоритет | Причина |
|---------|-----------|---------|
| score == 0 AND max >= 3 | **Критический** | Полностью отсутствует важный фактор |
| score == 0 AND max < 3 | **Высокий** | Отсутствует важный фактор |
| 0 < score < max AND ratio < 0.5 | **Высокий** | Менее половины баллов получено |
| 0 < score < max AND ratio >= 0.5 | **Средний** | Частично выполнено |
| score == max | **Нет** | Всё ок, рекомендация не нужна |

### Шаблон рекомендаций

```markdown

1. [Фактор] — score: X/max — [конкретная причина из current]
2. ...

### Высокий приоритет (Этот месяц)
1. [Фактор] — score: X/max — [конкретная причина]
2. ...

### Средний приоритет (Этот квартал)
```

## Экспертные чеклисты (для углублённого анализа)

Эти чеклисты используются для ручной экспертной проверки, не автоматизированной скриптом.

### Title Tag

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Существует | Каждая страница должна иметь уникальный title tag | Пройдено/Не пройдено |
| Длина | 50-60 символов | Пройдено/Требует работы/Не пройдено |
| Основное ключевое слово | Содержит целевое ключевое слово | Пройдено/Требует работы/Не пройдено |
| Позиция ключевого слова | Ключевое слово ближе к началу | Пройдено/Требует работы/Не пройдено |
| Название бренда | Включает бренд в конце | Пройдено/Требует работы/Не пройдено |

### Meta Description

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Существует | Каждая страница должна иметь meta description | Пройдено/Не пройдено |
| Длина | 150-160 символов | Пройдено/Требует работы/Не пройдено |
| Основное ключевое слово | Естественно включает целевое ключевое слово | Пройдено/Требует работы/Не пройдено |
| Call to action | Содержит причину для клика | Пройдено/Требует работы/Не пройдено |

### Иерархия заголовков (H1-H6)

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| H1 существует | Ровно один H1 на странице | Пройдено/Не пройдено |
| H1 содержит ключевое слово | Основное ключевое слово в H1 | Пройдено/Требует работы/Не пройдено |
| Логическая иерархия | H2 под H1, H3 под H2 | Пройдено/Требует работы/Не пройдено |

### Оптимизация изображений

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Alt текст | У каждого изображения есть alt | Пройдено/Требует работы/Не пройдено |
| Alt текст качество | Описывает изображение + ключевые слова | Пройдено/Требует работы/Не пройдено |
| WebP формат | Используется WebP для оптимизации | Пройдено/Требует работы/Не пройдено |

## Факторы ранжирования: Google vs Яндекс

| Группа факторов | Google | Яндекс | Комментарий |
|---|---|---|---|
| **Текстовые** | Высокое | Высокое | Обе системы |
| **Ссылочные** | Критично | Минимально (после 2013) | Google всё ещё нужны ссылки |
| **Поведенческие** | Косвенные | КРИТИЧНЫ | Яндекс использует Метрику |
| **Региональность** | По IP | Сильный фактор | Привязка в Вебмастере |
| **Коммерческие** | Среднее | Высокое | Цены, доставка, контакты |
| **Технические** | Важно | Важно | Обе системы |
| **Авторство/E-E-A-T** | E-E-A-T | Вега-алгоритм | Похожие концепции |

## Поведенческие факторы (требуют доступа к Яндекс.Метрике)

Эти факторы нельзя измерить автоматически — требуется доступ к Яндекс.Метрике.

| Фактор | Что измерять | Влияние на Яндекс |
|---|---|---|
| CTR сниппета | Кликабельность в выдаче | Прямой фактор |
| Last click | Пользователь не вернулся в выдачу | Сильный сигнал релевантности |
| Время на сайте | Средняя длительность сессии | Чем больше — тем лучше |
| Глубина просмотра | Количество страниц за визит | Показатель вовлечённости |
| Показатель отказов | Процент быстрых уходов | Чем меньше — тем лучше |

## Ключевые принципы

- SEO-аудиты должны быть образовательными, не только диагностическими
- Всегда предоставляйте "до" и "после" — что изменить
- Связывайте SEO-улучшения с бизнес-результатами
- Используйте данные автоматического скрипта как отправную точку
- Приоритизируйте рекомендации по усилие/влияние
- Для России: Яндекс важнее Google (70/30)
- **Шкала 0-20 для каждой системы, сумма факторов = 20**
- **Автоматическая генерация чеклистов и рекомендаций на основе данных из `scores.google_seo_breakdown` и `scores.yandex_seo_breakdown`**
