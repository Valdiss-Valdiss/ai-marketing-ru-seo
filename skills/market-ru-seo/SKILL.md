# SEO-аудит контента (Google + Яндекс)

## Назначение скилла

Проведение комплексного SEO-аудита веб-страницы или сайта для двух поисковых систем: **Google** и **Яндекс**. Скилл сочетает автоматический анализ через `scripts/analyze_page.py` с экспертной ручной проверкой.

**Особенности:**
- Google и Яндекс имеют разные алгоритмы и факторы ранжирования
- Для России рекомендуемый вес: **Яндекс 70%, Google 30%**
- Автоматический скрипт рассчитывает оба Score и комбинированный

## Когда использовать

- Пользователь предоставляет URL и просит SEO-анализ
- Пользователь хочет улучшить позиции в органической выдаче
- Пользователь спрашивает про on-page SEO, meta-теги, технический SEO
- Запускается командой `/market-ru seo <url>`

## Как выполнить

### Шаг 1: Запуск автоматического анализа

```bash
python3 scripts/analyze_page.py <url>
```

Скрипт извлекает данные и рассчитывает:
- **google_seo** — Score для Google (0-10)
- **yandex_seo** — Score для Яндекс (0-10)
- **seo_combined** — Комбинированный Score (Google×0.30 + Яндекс×0.70)

### Шаг 2: Чеклист On-Page SEO

Оцените каждый элемент. После каждого чеклиста — дополнение для Яндекс.

## Чеклисты Google (базовые)

### Title Tag

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Существует | Каждая страница должна иметь уникальный title tag | Пройдено/Не пройдено |
| Длина | 50-60 символов | Пройдено/Требует работы/Не пройдено |
| Основное ключевое слово | Содержит целевое ключевое слово | Пройдено/Требует работы/Не пройдено |
| Позиция ключевого слова | Ключевое слово ближе к началу | Пройдено/Требует работы/Не пройдено |
| Название бренда | Включает бренд в конце | Пройдено/Требует работы/Не пройдено |

#### Дополнение для Яндекс

| Критерий | Яндекс-особенность | Рекомендация |
|---|---|---|
| Длина | Яндекс показывает больше символов (~70-80) | Можно длиннее чем для Google |
| Сниппеты | Яндекс может менять title в сниппете | Используйте чёткие фразы |
| Региональность | Title может включать город/регион | Добавить для локального SEO |
| Морфология | Яндекс понимает все формы слова | Достаточно одной формы |

### Meta Description

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Существует | Каждая страница должна иметь meta description | Пройдено/Не пройдено |
| Длина | 150-160 символов | Пройдено/Требует работы/Не пройдено |
| Основное ключевое слово | Естественно включает целевое ключевое слово | Пройдено/Требует работы/Не пройдено |
| Call to action | Содержит причину для клика | Пройдено/Требует работы/Не пройдено |

#### Дополнение для Яндекс

| Критерий | Яндекс-особенность | Рекомендация |
|---|---|---|
| Влияние на ранжирование | Не влияет напрямую | Не критично для ранжирования |
| Влияние на CTR | Влияет на кликабельность сниппета | Важно для поведенческих факторов |
| Формат | Может быть короче | 140-160 символов достаточно |

### Иерархия заголовков (H1-H6)

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| H1 существует | Ровно один H1 на странице | Пройдено/Не пройдено |
| H1 содержит ключевое слово | Основное ключевое слово в H1 | Пройдено/Требует работы/Не пройдено |
| H1 отличается от title | H1 и title tag разные (но связаны) | Пройдено/Требует работы/Не пройдено |
| Логическая иерархия | H2 под H1, H3 под H2 | Пройдено/Требует работы/Не пройдено |

#### Дополнение для Яндекс

| Критерий | Яндекс-особенность | Рекомендация |
|---|---|---|
| Нейросети | Яндекс использует YATI, понимает структуру | Чёткая структура помогает алгоритмам |
| Смысловое соответствие | Заголовки должны отражать суть секции | Используйте описательные H2/H3 |
| Списки и нумерация | Яндекс любит структурированный контент | Добавляйте маркированные списки |

### Оптимизация изображений

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Alt текст | У каждого изображения есть alt | Пройдено/Требует работы/Не пройдено |
| Alt текст качество | Описывает изображение + ключевые слова | Пройдено/Требует работы/Не пройдено |
| Имена файлов | Описательные (не IMG_001.jpg) | Пройдено/Требует работы/Не пройдено |
| Размер файлов | WebP, сжатые | Пройдено/Требует работы/Не пройдено |

#### Дополнение для Яндекс

| Критерий | Яндекс-особенность | Рекомендация |
|---|---|---|
| Поиск по картинкам | Яндекс.Картинки — отдельный трафик | Alt тексты критичны для визуального поиска |
| WebP формат | Яндекс поддерживает WebP | Конвертируйте в WebP |
| Турбо-страницы | Оптимизация изображений важна | Lazy loading для скорости |

### Внутренние ссылки

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Внутренние ссылки присутствуют | Страница ссылается на другие страницы | Пройдено/Требует работы/Не пройдено |
| Текст якоря | Описательный (не "кликните здесь") | Пройдено/Требует работы/Не пройдено |
| Глубокие ссылки | Ссылки на конкретные страницы | Пройдено/Требует работы/Не пройдено |

#### Дополнение для Яндекс

| Критерий | Яндекс-особенность | Рекомендация |
|---|---|---|
| Анкорный текст | Яндекс учитывает текст ссылок | Используйте естественные анкоры |
| Контекстность | Ссылки в релевантном контексте | Не ставьте ссылки в unrelated контенте |
| Вес страниц | Link Juice распределяется по структуре | Каскадная структура: главная → категории → страницы |

### Структура URL

| Критерий | Лучшая практика | Проверка |
|---|---|---|
| Читаемый | URL человекочитаемый | Пройдено/Требует работы/Не пройдено |
| Ключевые слова | URL содержит ключевые слова | Пройдено/Требует работы/Не пройдено |
| Длина | Менее 75 символов | Пройдено/Требует работы/Не пройдено |
| Дефисы | Слова разделены дефисами | Пройдено/Не пройдено |

#### Дополнение для Яндекс

| Критерий | Яндекс-особенность | Рекомендация |
|---|---|---|
| ЧПУ (человекочитаемые URL) | Критично для Яндекс | Только латиница, дефисы |
| Кириллица в URL | ПЛОХО — не используйте | Яндекс может некорректно индексировать |
| Параметры | Минимум параметров в URL | Используйте чистые URL |

## Факторы ранжирования: Google vs Яндекс

| Группа факторов | Google | Яндекс | Комментарий |
|---|---|---|---|
| **Текстовые** | Высокое | Высокое | Обе системы |
| **Ссылочные** | Критично | Минимально (после 2013) | Google всё ещё нужны ссылки |
| **Поведенческие** | Косвенные | КРИТИЧНЫ | Яндекс использует Метрику |
| **Региональность** | По IP | Сильный фактор | Привязка в Вебмастере |
| **Коммерческие** | Среднее | Высокое | Цены, доставка, контакты |
| **Технические** | Важно | Важно | Обе системы |
| **Авторство/E-E-A-T** | E-E-A-T | Вега-алгоритм | Похожие концепции |

- [ ] Счётчик установлен

- [ ] Цели настроены

### robots.txt для Яндекс

- [ ] Clean-param не блокирует важные URL
- [ ] Не заблокированы page?tracking_id параметры
- [ ] Sitemap.xml указан

## Поведенческие факторы (требуют доступа к Яндекс.Метрике)

Эти факторы нельзя измерить автоматически — требуется доступ к Яндекс.Метрике.

| Фактор | Что измерять | Влияние на Яндекс |
|---|---|---|
| CTR сниппета | Кликабельность в выдаче | Прямой фактор |
| Last click | Пользователь не вернулся в выдачу | Сильный сигнал релевантности |
| Время на сайте | Средняя длительность сессии | Чем больше — тем лучше |
| Глубина просмотра | Количество страниц за визит | Показатель вовлечённости |
| Показатель отказов | Процент быстрых уходов | Чем меньше — тем лучше |

**Как улучшить:**
- Улучшайте Title и Description для повышения CTR
- Добавляйте интерактив (калькуляторы, квизы)
- Структурируйте контент: подзаголовки, списки, таблицы
- Первым экраном давайте ответ на запрос

## E-E-A-T для Яндекс (аналог Google)

Яндекс использует алгоритм **Вега** для оценки авторитетности.

| Критерий | Проверка |
|---|---|
| Профиль автора | Ссылки на эксперта с опытом |
| Страница "О компании" | История, команда, достижения |
| Контактная информация | Адрес, телефон, реквизиты |
| Отзывы | На сайте + Яндекс.Карты |
| Упоминания в СМИ | Без обязательной ссылки |

## Ключевые принципы

- SEO-аудиты должны быть образовательными, не только диагностическими
- Всегда предоставляйте "до" и "после" — что изменить
- Связывайте SEO-улучшения с бизнес-результатами
- Используйте данные автоматического скрипта как отправную точку
- Приоритизируйте рекомендации по усилие/влияние
- Для России: Яндекс важнее Google (70/30)
