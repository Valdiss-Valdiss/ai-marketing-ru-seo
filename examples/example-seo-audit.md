## Приоритизированные рекомендации

### Критические (Исправить немедленно)

1. **Добавить meta description** (Impact: +15% CTR из поиска)
   - Текущий: Отсутствует
   - Рекомендуемый: Описательный текст 140-160 символов с CTA

2. **Установить Яндекс.Метрику** (Impact: Отслеживание поведенческих факторов)
   - Без Метрики невозможно оптимизировать поведение пользователей
   - Яндекс использует эти данные для ранжирования

3. **Добавить сайт в Яндекс.Вебмастер** (Impact: Управление индексацией)
   - Настроить региональность
   - Отслеживать ошибки индексации

### Высокий приоритет (Этот месяц)

1. Расширить Title до 50-70 символов с ключевыми словами
2. Перейти на HTTPS (критично для Яндекс)
3. Создать sitemap.xml и добавить в robots.txt
4. Добавить Schema.org (Organization)

### Средний приоритет (Этот квартал)

1. Добавить внутренние ссылки (минимум 3-5)
2. Настроить Турбо-страницы (для мобильного SEO)
3. Улучшить E-E-A-T: добавить информацию о компании
4. Добавить больше контента (сейчас только 23 слова)

### Низкий приоритет (Когда позволяют ресурсы)

1. Оптимизировать изображения (если появятся)
2. Добавить FAQ секцию для сниппетов
3. Создать блог с регулярными публикациями
