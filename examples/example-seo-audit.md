## Приоритизированные рекомендации

### Критические (Исправить немедленно)

1. **Добавить H1 с ключевым словом** — Ровно один H1 на странице с основным ключевым словом. `<h1>Главная</h1>`
1. **Добавить Schema.org разметку** — Рекомендуемые типы: LocalBusiness, Store, Service. Найдены: главная

### Высокий приоритет (Этот месяц)

1. **Улучшить Title Tag** — Минимум 50-60 символов с ключевыми словами и названием бренда. `<title>Главная — главная в example.ai</title>`
1. **Добавить Meta Description** — 140-160 символов с CTA и ключевыми словами. `<meta name='description' content='[Ваше краткое описание с ключевыми словами: главная]'>`
1. **Alt тексты для изображений** — Добавить описательные alt к изображениям для Яндекс.Картинки. `<img alt="описание изображения">`
1. **Установить HTTPS** — Перенаправить HTTP на HTTPS, обновить canonical. Без HTTPS сайт не получит высокие позиции в Яндекс. `301 redirect HTTP → HTTPS`
1. **Установить Яндекс.Метрику** — Для анализа поведенческих факторов — критичных для Яндекс.

### Средний приоритет (Этот квартал)

1. **Добавить коммерческие маркеры** — Телефоны, email, адреса, ИНН/ОГРН для Яндекс.
1. **Расширить микроразметку** — Добавить Schema.org помимо OG тегов.
